Fixes a WebKit resize feedback loop found while testing real ReAI ledger previews, including an unsupported PDF 2.0 page.

The embedded viewer now refits only when width changes, schedules layout work outside ResizeObserver delivery and avoids redundant renders at an unchanged scale. Height-only changes no longer render the same page repeatedly. Failed/reopened documents also clear their ready state, and opening a new document restores automatic fitting.

A public Skald-generated rejection fixture and a regression test cover height changes, render counts and error-state transitions across Chromium, Firefox and WebKit. Also corrects ancillary benchmark bundle metadata and makes the development harness measure the configured server's assets. Timing and memory records are unchanged.

The bounded skald-pdf2-v1 profile and 1.0 API are unchanged. JPEG XL PDF embedding remains experimental.
