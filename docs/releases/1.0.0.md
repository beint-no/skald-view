Skald View 1.0.0 implements the bounded **skald-pdf2-v1** viewing profile for controlled Skald-generated documents.

- All 91 pinned Skald PDFs / 102 pages render and pass independent MuPDF comparisons.
- Adds axial RGB gradients, safe URI link metadata/overlays, readonly invisible signature fields, fill/stroke text and bounded ASCII85 decoding.
- Shared glyph outlines and a bounded exact-frame cache reduce tracked retention; native results expose immutable shared RGBA. Warm browser renders improve on the measured fixtures, with a small first-page cost. See the full before/after report.
- Provides a same-origin embedding protocol, Norwegian/English controls and a versioned browser archive with WASM, licenses, profile, source manifest and SHA-256 checksum.
- Tests cover three browser engines, malformed-input boundaries, codec roundtrips, cache equivalence and all representative application fixtures.

**Scope:** PDF 1.x, classic/hybrid xrefs, unsupported fonts and other out-of-profile features are explicit errors. Signature metadata does not verify cryptographic validity. JPEG XL PDF embedding remains provisional. This release does not claim general-purpose PDF compatibility, unrestricted-upload security certification or universal benchmark superiority.
